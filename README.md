# Steel Ball FM — Chrome / Brave

Lecteur radio compact au style noir, avec contour dégradé menthe/rose, recherche, favoris et réglage du volume.

## Fonctionnalités

- Lecture radio en arrière-plan grâce à un document offscreen (Manifest V3)
- Catalogue Radio Browser, recherche et filtre par pays
- Favoris et volume sauvegardés localement
- Affichage des titres/artistes lorsque le flux radio fournit des métadonnées compatibles
- Aucune publicité ajoutée et aucun compte requis

## Installation dans Chrome ou Brave

1. Téléchargez et décompressez l’archive ZIP.
2. Ouvrez `chrome://extensions` dans Chrome ou `brave://extensions` dans Brave.
3. Activez le **Mode développeur**.
4. Cliquez sur **Charger l’extension non empaquetée** et sélectionnez le dossier `steel-ball-fm-chrome`.
5. Épinglez Steel Ball FM à la barre d’outils si vous le souhaitez.

## Remarques

La disponibilité dépend des serveurs des radios. Certaines stations peuvent être indisponibles ou incompatibles avec le navigateur. Les métadonnées des titres ne sont pas fournies par toutes les stations.
